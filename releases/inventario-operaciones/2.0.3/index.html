De demostración a solución real

Todos los registros son ficticios. Scores, oportunidades y escenarios ilustran capacidades analíticas; no provienen de un modelo predictivo entrenado. Para un cliente real se acuerdan fuentes, permisos, definiciones, validación y medición del resultado.

La versión estática no conecta ERP, ejecuta ETL ni sincroniza tareas. API, IA y automatización se integran como servicios del proyecto cuando sean necesarios.
